# PipelineControl.UI

.NET 8 WPF 工控 HMI。当前运行入口为 `总控`、`IO 点位`、`通讯`。

## 当前页面

- `总控`：显示板卡通讯和整线状态，提供 `自动开启` / `自动关闭`。
- `IO 点位`：显示 X 输入和 Y 输出，手动模式下支持单点和扩展卡1动作组点动；本体 X8 线头防呆光电感应时禁止扩展卡1 Y8 线头气缸伸出。
- `通讯`：配置 PC IP、主卡 IP、扩展卡数量、扫描周期、心跳和仿真模式。

## 自动升降 v1

- 自动开启前必须已连接 IO 板卡，且手动输出已复位。
- 线头：X1 有信号时上升到 X3 停；X1 无信号先等 3 秒，再下降到 X2 停。
- 线尾：X5 有信号时下降到 X6 停；X5 无信号先等 3 秒，再上升到 X7 停。
- IO 控制卡本体 Y0 在线头 X2 下限位有信号且 X1 行程无信号时 ON；Y1 同条件输出，但 X0 有信号时禁止输出；X1 行程一有信号时 Y0/Y1 都 OFF。
- IO 控制卡本体 Y2-Y9 自动开启后保持 ON，自动关闭或异常时 OFF。
- 自动输出包含 IO 控制卡本体 Y0-Y9（pointNo 1-10，其中 Y0/Y1 为条件输出）和扩展卡1 Y0-Y9（pointNo 17-26）。
- 扩展卡1 Y8/Y9 线头/线尾气缸按升降到位触发 3 秒脉冲：线头上升到 X3 上限后触发 Y8，线尾下降到 X6 下限后触发 Y9；线头 Y8 仍受本体 X8 线头防呆光电限制。
- 自动关闭只关闭自动流程输出，不调用整板 Reset。
- 30 秒不到位、上下限同时触发、通讯断开或写输出失败会进入异常。
