## P17 当前完成状态

### 独立窗口

大屏窗口文件：

```text
src\PipelineControl.UI\Views\Windows\DashboardWindow.xaml
src\PipelineControl.UI\Views\Windows\DashboardWindow.xaml.cs
src\PipelineControl.UI\ViewModels\Windows\DashboardViewModel.cs
```

窗口特性：

- 独立于主操作窗口，非模态显示。
- 默认 Dark 主题。
- 支持右键菜单「切换主题」「关闭」。
- F11 进入真全屏，Esc 退出全屏。
- 鼠标静止 5 秒自动隐藏，鼠标移动恢复。
- 外层使用 `Viewbox Stretch="Uniform"`，内部设计画布固定 `1920 × 1080`。
- 关闭大屏窗口不影响主操作窗口。

### 启动方式

主窗口中左侧 QUICK 区「打开大屏窗口」会执行：

```csharp
serviceProvider.GetRequiredService<DashboardWindow>().Show();
```

另外 `App.xaml.cs` 已支持命令行直启大屏：

```powershell
src\PipelineControl.UI\bin\Debug\net8.0-windows\PipelineControl.UI.exe --dashboard
```

这是为了预览大屏时不用先点主窗口。

### 双主题

主题服务：

```text

src\PipelineControl.UI\Services\Theme\ThemeService.cs
```

主题资源：

```text
src\PipelineControl.UI\Themes\DashboardDarkTheme.xaml
src\PipelineControl.UI\Themes\DashboardEditorialTheme.xaml
```

关键规则：

- 两套主题使用同一组 `Dashboard.*` Key。
- 窗口启动时根据 `IThemeService.Current` 加载主题字典。
- 切换主题时替换 `DashboardWindow.Resources.MergedDictionaries` 中的大屏主题字典。
- 大屏窗口内颜色必须使用 `DynamicResource Dashboard.*`。
- Dashboard 主题只作用于大屏窗口，不污染主 Shell/P03/P04/P07。

## 最近修复点

大屏最初打不开，是因为 `DashboardAlarmBanner.xaml` 里 `Run.Text` 绑定到了 `AlarmRecord.SeverityText` 等只读属性，WPF 把 `Run.Text` 当成默认双向绑定处理，导致窗口 `Show()` 抛异常：

```text
无法对 AlarmRecord 的只读属性 SeverityText 进行 TwoWay 或 OneWayToSource 绑定
```

已修复为：

```xml
<Run Text="{Binding CurrentAlarm.SeverityText, Mode=OneWay}" />
```

同类只读绑定也都显式加了 `Mode=OneWay`。

## 继续开发约束

继续开发时遵守：

1. 不要重做 Shell。
2. 不要引入 `MaterialDesignInXaml`、`Prism`、`MahApps`。
3. 不要使用 `WindowChrome` 自定义标题栏。
4. 不要连接真实 IO 卡。
5. 不要接数据库，当前阶段数据优先 Mock。
6. 页面颜色走资源字典。
7. 页面字号走 `Themes/Typography.xaml`。
8. 大屏颜色走 `Dashboard.*` 动态资源。
9. View 的 `.xaml.cs` 尽量只保留窗口行为或 DependencyProperty，不写业务逻辑。
10. 优先使用 `CommunityToolkit.Mvvm` 源生成器。
11. 新增 Shell 内容页要接入 `PageNavigator`，并在 `App.xaml.cs` 注册页面和 ViewModel。
12. 报警相关共享状态必须走 Singleton `IAlarmService`。
