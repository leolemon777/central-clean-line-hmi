# Pattern:同步输出动作组与方向互锁

> 适用：一个物理动作需要多个 Y 点同时输出，或者同一机构存在上升/下降、伸出/缩回等互斥方向。

## 本项目事实

中央净软线扩展卡1有同步输出点：

| 动作 | 点位 | 说明 |
|------|------|------|
| 线头电缸上升 | Y0 + Y1 | 两点同时通才触发 |
| 线头电缸下降 | Y2 + Y3 | 与线头上升互锁 |
| 线尾电缸上升 | Y4 + Y5 | 两点同时通才触发 |
| 线尾电缸下降 | Y6 + Y7 | 与线尾上升互锁 |
| 线头气缸伸出 | Y8 | 单点动作 |
| 线尾气缸伸出 | Y9 | 单点动作 |

## 设计原则

### 1. UI 暴露动作，不暴露危险组合

原始 Y 点可以显示状态，但同步点不能让用户直接点单点。

正确方式：

```text
动作按钮: 线头电缸上升
状态显示: Y0、Y1 一起亮
单点 Y0/Y1: 不允许单独操作
```

### 2. 同模块批量写入，避免中间态

如果 Y0/Y1 分两次写，现场可能出现短暂中间态：

```text
Y0 ON, Y1 OFF
```

同步点应尽量一次写整模块值。当前项目用：

```text
IoBoardService.WriteOutputsAsync
RealIoBoardDriver.WriteOutputModule
GA_SetExtDoValue / MC_SetExtDoValue
```

### 3. 上升/下降采用禁止并提示，不自动切换

反方向已开时，不应该自动关闭当前方向再打开另一个方向。

正确行为：

```text
线头上升已 ON
用户按线头下降
=> 拒绝，提示先复位/松开当前方向
```

自动切换会隐藏危险中间态，也可能造成机构冲击。

## 反模式

| 反模式 | 风险 |
|--------|------|
| 同步点允许单点操作 | 机构动作异常或无动作 |
| 成对点分两次写 | 出现短暂中间态 |
| 方向冲突时自动切换 | 现场不可预期动作 |
| 状态只显示动作按钮，不显示原始 Y | 现场无法确认实际点位 |
