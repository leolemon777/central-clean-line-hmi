# 伺服现场调试 CheckList · RS485 Modbus + 禾川 SV-X4EA

> 用途：工控机上电后，伺服电机上电联调的可打印逐条勾选清单。
> 适用范围：中央净软线 HMI 伺服手动测试盘（4 轴，驱动器侧 RS485 Modbus RTU；当前软件通过 TCP→RTU 网关访问）。
> 配套文件：`src/PipelineControl.UI/Resources/servo-registers.json`、`implementation-notes.md`。

---

## 0. 拓扑与准备

- 实物型号：照片铭牌为 **SV-X4EA040A-AE-00**，400W，X4EA-AE 系列。
- 驱动器通讯口：X4EA 安装说明书确认 **CN4/CN5 为 RS485 通讯接口**。
- 当前 HMI 软件拓扑：工控机（TCP 客户端） → **有人 USR-TCP232 串口服务器（Modbus TCP↔RTU 网关）** → RS485 总线 → 4 台禾川 SV-X4EA 伺服（站号 1–4，CN4/CN5 手拉手）。
- 如果现场改成 **电脑直连 USB-RS485 / COM 口**：当前 HMI 不能直接用 `GatewayIp/GatewayPort` 连接，必须先新增 Modbus RTU 串口驱动；不要拿现有 HMI 直接试。
- 准备工具：
  - [ ] Modbus Poll 软件（验证链路用）
  - [ ] 网线（工控机 ↔ USR 模块）
  - [ ] 有人配置工具 或 浏览器（进模块 Web）
  - [ ] 禾川 SV-X4EA 安装说明书 + 厂家给的 `禾川X5-Modbus控制.docx`（X5 脉冲型 Modbus 控制资料，用于核对 P09/P03/P04 地址规则）
  - [ ] 确认 USR-TCP232 是 RS485 版本（410s / 304 等），纯 RS232 版不可用

## 1. 有人 USR-TCP232 模块配置

网络设置：
- [ ] IP 地址获取方式：**静态 IP**
- [ ] IP 地址：与工控机**同网段**（= HMI 通讯页 `GatewayIp`，如 192.168.1.30）
- [ ] 子网掩码 / 默认网关：按工控机网段填
- [ ] **本地端口号：502**（= HMI 通讯页 `GatewayPort` 默认；若改此处，HMI 须同步）

串口设置（RS485 侧，必须与伺服一致）：
- [ ] 接口：**RS485**（A/B 端子或 RJ45 第 4/5 脚）
- [ ] 波特率：与 `P09.01` 一致；厂家资料默认值 `2 = 9600 bps`
- [ ] 数据位：**8**
- [ ] 校验/停止位：与 `P09.02` 一致；厂家资料默认值 `0 = 无校验，2 停止位`（不是 1 停止位）
- [ ] 流控：无

工作模式 + 网关（最关键）：
- [ ] 工作模式：**TCP Server**
- [ ] 协议/转换：选 **「Modbus TCP」**（启用 TCP→RTU 转换）
- [ ] **不要选「无 / 透传」**（否则 MBAP 帧原样甩到串口，伺服收 RTU 帧对不上）
- [ ] 串口打包时间：设小（5–10ms），避免轮询/心跳超时

有人云（可选）：
- [ ] 如需云端管：填设备 ID / 注册服务器(usr.cn) / 通讯密码；不填也能本地用

- [ ] **保存并重启模块**

## 2. 禾川 SV-X4EA 驱动器前置参数（上电前先设）

- [ ] `P09.00`：伺服轴地址，4 台分别设为 **1 / 2 / 3 / 4**（范围 1–247，必须唯一）
- [ ] `P09.01`：Modbus 波特率，默认 `2 = 9600 bps`
- [ ] `P09.02`：Modbus 数据格式，默认 `0 = 无校验，2 停止位`
- [ ] `P09.04`：通信应答延时，先保持默认；链路慢或轮询超时时再调整
- [ ] `P00.01 = 1`：速度模式
- [ ] `P09.05 = 2H`：开通信 DI 控制权（否则使能写不进去）
- [ ] `P04.01 = 0`：取消物理使能端口分配
- [ ] `P03.00 = 0`：数字给定速度模式（当前 HMI 临时调试方案写 `P03.03/0303H`）
- [ ] `P03.03 = 0`：上电前先置 0，HMI 点动时再写目标 rpm
- [ ] `P09.11`：通信 DI 断线超时，厂家资料提示出厂 5s；HMI 心跳周期必须小于该值

---

## 3. Modbus Poll 打通验证（开 HMI 前先做）

连接参数（当前 HMI 同款 TCP→RTU 网关拓扑）：
- [ ] Connection：Modbus TCP/IP
- [ ] IP Address：`模块IP`（即步骤 1 的 GatewayIp）
- [ ] Port：**502**
- [ ] Slave ID：先试 **1**

如果是电脑直连 USB-RS485：
- [ ] Connection 应选 Modbus RTU/Serial，串口格式按 `P09.01/P09.02`；但当前 HMI 暂不支持这种直连方式。

使能寄存器验证（ServoOn = `3607H`）：
- [ ] 用 FC06 写 `3607H = 2` → 伺服应进入使能
- [ ] 用 FC03 读 `3607H` → 期望值 **2**
- [ ] FC06 写 `3607H = 0` → 伺服应断开使能

速度寄存器验证（当前 SpeedCommand = `0303H/P03.03`）：
- [ ] 先使能（写 `3607H=2`）
- [ ] FC06 写 `0303H = 小值`（如 100 rpm，勿超最大）
- [ ] 立刻在驱动器面板监控 `P21.03 速度指令`：若 `P21.03` 变为对应 rpm，再观察轴是否转动
- [ ] 若 `P21.03=目标速度` 但电机不转，继续查使能状态、抱闸、STO、安全/急停、故障、主回路和电机/编码器接线
- [ ] 若 `P21.03=0` 或完全不动/报错 → 先确认驱动器 `P03.00=0` 是否已停机生效
- [ ] 写 `0303H = 0` 停转，写 `3607H=0` 断使能

逐轴复测：
- [ ] 站号 2 / 3 / 4 重复上述使能+速度验证

## 4. HMI「通讯」页填写（ServoComm，共 10 项）

- [ ] 伺服网关 IP（GatewayIp）：= 步骤 1 的模块 IP
- [ ] 网关端口（GatewayPort）：502
- [ ] 1# 站号（Axis1Station）：1
- [ ] 2# 站号（Axis2Station）：2
- [ ] 3# 站号（Axis3Station）：3
- [ ] 4# 站号（Axis4Station）：4
- [ ] 扫描周期（ScanCycleMs）：100（默认）
- [ ] 心跳周期（HeartbeatCycleMs）：3000（默认，**必须 ≤5s**，否则真机自动断使能）
- [ ] 默认转速（DefaultSpeedRpm）：小值
- [ ] 最大转速（MaxSpeedRpm）：限幅
- [ ] **保存 → 重启程序**（这些字段 `isRestartRequired=true`）

---

## 5. HMI「伺服」页测试顺序

- [ ] 顶部点 **连接**（ServoService 建 NModbus `ModbusIpMaster`，单 TcpClient + lock 串行）
- [ ] 确认 4 轴状态轮询正常、无离线/失败计数
- [ ] 确认页面处于 **点动** + **单轴**，默认转速先用 **100 rpm** 或更低
- [ ] 逐轴：**使能** → **按住正转/反转**（松开必须停）→ 看轴短暂转动 → **停用**
- [ ] 四轴各来一遍
- [ ] 顶部 **急停**：验证全局断使能
- [ ] 看结构化日志（IAppLogService），确认心跳续写在 ≤5s 内

## 6. 已知风险 / 坑

- [ ] **当前 HMI 已改写 `0303H/P03.03`**：驱动器侧必须设 `P03.00=0`，否则上位机写入的数字给定速度不会作为当前速度来源。
- [ ] **原速度候选 `0324H` 暂停使用**：`SV-X5` 手册确认 P03.36 地址规则为 `03H << 8 + 24H = 0324H`，但 P03.36 是“第 1 段速度/内部多段速度设定值”；它和 `P03.00=4` 通信给定可能不是同一速度通道。
- [ ] **故障复位半残**：`X4EA` 脉冲型故障码/通信复位地址厂家未给（X4 手册是 EtherCAT，不通用于本机），`ServoService.ResetFaultAsync` 目前只记日志、不真正复位；真机通信故障可能需手动在驱动器复位。
- [ ] **自动化测试不等于真机通过**：本机无硬件验证已通过，现场仍必须用 Modbus Poll + HMI 单轴低速点动确认真实动作。
- [ ] **站号在驱动器上设**，不在 USR 模块上；模块只认 IP+端口。
- [ ] **波特率/校验/停止位 app 管不到**，必须模块与伺服一致，尤其注意默认 `P09.02=0` 是无校验、2 停止位。
- [ ] **通信给定和 IO 多段速是两套方案**：当前 HMI 走 `P03.00=4` 通信给定；厂家 `禾川X5-IO多段速运行.docx` 的 `P03.00=3 + MI_SEL1~4` 是纯 IO 多段速，不是当前软件方案。

## 7. 寄存器速查

| 名称 | 地址 | 读写 | 值 | 说明 |
|---|---|---|---|---|
| ServoOn | `3607H` | 写 | 2=开 / 0=关 | 伺服使能，厂家资料确认 |
| SpeedCommand | `0303H` | 写 | 带符号 rpm（如 100） | 当前临时调试地址；对应 P03.03，驱动器侧需 `P03.00=0` |

参数速查：

| 参数 | 建议值 | 说明 |
|---|---:|---|
| `P09.00` | 1/2/3/4 | 站号，设在每台伺服驱动器上 |
| `P09.01` | 2 | 9600 bps，必须和 USR 串口侧一致 |
| `P09.02` | 0 | 无校验，2 停止位，必须和 USR 串口侧一致 |
| `P09.05` | 2H | 开通信 DI 控制权 |
| `P09.11` | 默认 5s | 通信 DI 断线超时，HMI 心跳必须小于它 |
| `P00.01` | 1 | 速度模式 |
| `P03.00` | 0 | 数字给定速度；当前 HMI 写 P03.03/0303H |
| `P03.03` | 0/目标rpm | 速度指令设定值；HMI 点动时写目标 rpm，停止时写 0 |
| `P04.01` | 0 | 取消物理 S_ON 分配，避免和通信使能冲突 |

轴定义（servo-registers.json）：1#=站1，2#=站2，3#=站3，4#=站4。
