# Acceptance Criteria

> 触发条件：验收口径反复被脑补，或者任务卡里的验收开始重复。

## 全局完成标准

- [ ] 功能行为满足 requirements。
- [ ] 非目标没有被误做。
- [ ] quick verify 和 full verify 的预期结果明确。
- [ ] 相关文档或任务卡已更新。
- [ ] 风险和未完成项已说明。

- [ ] 输入验证覆盖边界值、非法值、权限不足。
