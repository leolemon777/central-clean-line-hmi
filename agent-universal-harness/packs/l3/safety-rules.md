# Safety Rules

> 触发条件：真实硬件、工业控制、设备动作、资金、生产数据、对外写操作。

## 通用安全规则

- 真实世界副作用默认禁止，除非任务卡明确预授权。
- 所有高风险操作先 dry-run / simulation，再人工确认。
- 任何安全联锁、急停、限位、回零逻辑变更必须单独审查。
- 默认 fail closed：不确定时停止，不继续执行。

## 硬件 / 设备项目

- UI 不得绕过控制抽象直接驱动硬件。
- 运动命令必须有边界、速度、加速度、超时限制。
- 急停、限位、联锁必须有仿真测试或硬件台架验证计划。
- 真实设备地址不得硬编码在代码、日志或任务卡中。

## 数据 / 资金 / 外部写操作

- 删除、迁移、批量更新必须有备份、dry-run、回滚或补偿策略。
- 支付、发信、写 API 必须有 sandbox 或 mock。
- 生产数据默认只读；写入必须专项授权。

## 停止条件

触发任意一项，立即停止并请求人类确认：

- 即将触发真实动作。
- dry-run 结果与预期不一致。
- 发现配置指向生产环境。
- 安全检查、联锁、权限校验被绕过或弱化。
