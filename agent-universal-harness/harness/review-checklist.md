# 审查清单

用途：Agent 每轮自审 + 人类提交前抽查 + Reviewer 会话输出框架。

Reviewer 输出分级：Blocking / Non-blocking / Missing tests / Safety risks。

## 范围

- [ ] diff 是否只含任务相关文件。
- [ ] 有无夹带无关重构、格式化、依赖变更。
- [ ] 是否超过任务卡 Size Check 或 stop rule S9。

## 正确性

- [ ] verify 输出是否真实：命令、路径、退出码、日志格式是否对得上。
- [ ] 有无删除、跳过、注释掉、弱化断言的测试。
- [ ] 新逻辑的边界条件和错误路径有测试覆盖吗。
- [ ] 声称的验收标准是否逐条有证据。

## 安全

- [ ] 有无硬编码密钥、凭证、内网地址、生产配置。
- [ ] 输入校验、权限检查有无被绕过或删除。
- [ ] 不可逆操作、对外写操作、硬件动作有无确认防护。
- [ ] L2+ 硬件类：UI 是否经由抽象接口而非直接控制硬件。
- [ ] L2+ 硬件类：急停、限位、联锁、回零等安全逻辑是否被触碰。

## 架构

- [ ] 依赖方向是否符合 architecture 文档（如有）。
- [ ] 是否引入了值得写 ADR 的决策而没写。
- [ ] 是否把 spike 代码未经固化直接并入主干。

## 交接

- [ ] `reports/progress.md` 是否更新。
- [ ] 下一轮接手者是否能从 progress 了解状态、命令、风险和下一步。
